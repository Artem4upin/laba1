# Лабораторная работа: 

## Автор
Чупин Артем (Вариант 10)

## Цель
Освоение базового синтаксиса C++ и математических вычислений на примере механизма с кривошипом.

## Описание
Программа вычисляет скорость перемещения ползуна.

## Исходные данные
- Длина кривошипа: 3.7 см
- Длина шатуна и ползуна: 16.4 см
- Время вращения кривошипа: 1.6
- Угол вращения: 335

## Ожидаемые результаты
Программа выводит три значения периода:
- v1: результат по точной формуле
- v2: результат по приближенной формуле
- w: ускорение ползуна
